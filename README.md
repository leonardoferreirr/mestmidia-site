# MestMidia

Site da MestMidia (tráfego pago, Uberlândia). Vite + TypeScript, sem framework.

- Hero: Sistema Orbital do Lab 3D (Babylon.js), que vira gráfico com o scroll. Cópia em `src/3d/lab/`; a fonte é o repo `lab-3d`.
- Textos e dados editáveis em `src/config.ts` (WhatsApp, Instagram, sites, criativos, painel).

```bash
npm install
npm run dev     # http://localhost:5340
npm run build   # gera dist/
```

Na Vercel: framework Vite, build `npm run build`, saída `dist`.
